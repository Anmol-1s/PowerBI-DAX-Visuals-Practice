# Power BI DAX & Charts Practice

This repository contains my practice work in **Power BI**, focusing on **DAX formulas, data analysis, and different charts and visualizations**.

## Dataset

The practice is based on the **Financials table from Power BI Sample Data**.

The dataset contains information related to:

- Sales
- Gross Sales
- Profit
- COGS
- Discounts
- Units Sold
- Country
- Product
- Segment
- Discount Band
- Date

## DAX Practice

The repository includes practice with:

- SUM
- DIVIDE
- CALCULATE
- FILTER
- ALL
- IF
- Date functions
- Percentage calculations
- Profit Margin
- Sales Achievement
- Total Sales
- Total Profit
- Sales % of Total

## Practice Questions

The practice focuses on questions such as:

- What percentage of total sales does each country contribute?
- How does Gross Sales compare with Sales after discounts?
- Which country generates the highest profit?
- How does Profit Margin vary by Discount Band?
- Does selling more units relate to higher profit?
- How do different components affect the final profit?
- How do sales rankings change over time?
